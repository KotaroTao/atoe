# AtoE career

新卒・若手歯科衛生士向けキャリアサイト「AtoE career」のトップページプロトタイプです。

## Concept

- 歯科衛生士の「最初の3年」に特化
- 新卒、第二新卒、1〜3年目の若手DHを対象にする
- AtoE academyと連動する採用・教育・定着プラットフォーム
- 医院向けにはポイント課金 + 月額SaaS + 採用広報支援を想定
- 学生/若手DHには、給与や休日だけでなく教育体制・見学しやすさ・定着支援を見せる
